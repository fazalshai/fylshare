# Fylshare — Instant Anonymous File Sharing

**Live Website:** [https://fylshare.com](https://fylshare.com)

Fylshare is a fast, zero-registration file sharing platform built for instant device-to-device and team transfers. Upload files up to 1GB and share them immediately via a **6-digit retrieval code**, **direct link**, or **scannable QR code**.

## Key Features
- **Instant 6-Digit Code & QR Retrieval:** Upload up to 1GB with no account required and retrieve on any device via `/search?code=XXXXXX`.
- **Workspace Box (`/workspace`):** Create PIN-protected shared folders for labs, classrooms, and project teams.
- **Cloud Storage Architecture:** Powered by React, Tailwind CSS, Node.js/Express, MongoDB Atlas, and Firebase Cloud Storage.
