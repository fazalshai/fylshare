What is Fylshare?

Fylshare is a completely free, secure, and anonymous file sharing platform. You can upload files up to 1GB and receive a unique 6-digit retrieval code instantly — no email, no registration, no password required. The person you share with simply enters the code on our search page and downloads the file directly. It is the fastest way to share large files without any friction.

Founded on the principles of privacy by design, Fylshare uses AES-256 bit encryption to protect your files at rest and TLS 1.3 to secure them in transit. We built Fylshare for professionals, students, freelancers, and everyday users who need to move files quickly without leaving a digital trail.

Unlike Google Drive, Dropbox, or WeTransfer, Fylshare does not require an account. Every transfer is anonymous. Every file is encrypted. Files are ephemeral by design — they are meant to be transferred, not stored. This architecture radically reduces privacy risk compared to traditional cloud storage solutions.

Key Features

  • No Registration Required: Start sharing files in seconds. We never ask for your email, name, or phone number for anonymous transfers.
  • AES-256 Encryption: Every file uploaded to Fylshare is encrypted using the same standard used by governments and banks worldwide.
  • TLS 1.3 In Transit: Data in motion between your device and our servers is protected by the latest Transport Layer Security protocol.

How to Use Fylshare: Step-by-Step Guide

Step 1: Upload Your Files

  1. Visit fylshare.com on any device with a web browser.
  2. Type any name in the "Enter your name" field. This is just a label — you are not creating an account.
  3. Drag and drop one or more files onto the upload area, or click it to open your device file picker.
  4. Select files totaling up to 1GB. You can upload multiple files at once.
  5. Click the "Upload Now" button and wait for the upload to complete. This usually takes a few seconds to a couple of minutes depending on file size and your internet speed.
  6. When the upload is complete, you will see a success message with your unique 6-digit retrieval code. Note this code down — you will need to share it with the recipient.

Step 2: Share the Code

Send the 6-digit code to the person you want to receive the file. You can send it via WhatsApp, SMS, email, phone call, or any messaging platform. The code itself contains no sensitive information.

Step 3: Recipient Downloads the File

  1. The recipient visits fylshare.com/search.
  2. They enter the 6-digit code in the search field and press Enter or click "Find Files".
  3. A list of all uploaded files associated with that code appears.
  4. They click on any file to begin the download directly to their device.

Workspace Box: Persistent Shared Folders for Teams

For teams and ongoing projects, Fylshare offers the Workspace Box feature. A Workspace Box is a persistent, PIN-protected shared folder hosted on encrypted cloud infrastructure. Unlike the anonymous 6-digit code system, a Workspace Box stays active until you delete it, making it ideal for regular collaboration.

To create a Workspace Box, visit fylshare.com/workspace. Choose a unique Box Name, set a PIN, and your Box is created instantly. All team members who know the Box Name and PIN can access it from any device at any time. They can upload files into the Box or download any file stored in it.

A Workspace Box replaces the need for shared Google Drive folders, email File attachments, or Slack channel files — all of which create persistent, uncontrolled data trails. The Box gives you controlled, encrypted storage with zero vendor data scanning.

Security & Privacy: Our Architecture

Privacy is not a feature at Fylshare — it is the fundamental design principle. Every architectural decision was made to minimize data collection and maximize security.

End-to-End Encryption

While Fylshare does not perform client-side (in-browser) encryption before upload, all data is protected in two critical stages. First, the transfer from your device to our servers is encrypted with TLS 1.3, the latest and most secure version of Transport Layer Security. This prevents any third party on the network — including your ISP or a Wi-Fi snooper — from reading your data in transit. Second, all files are stored using AES-256 encryption at rest, managed by Google Cloud's Key Management Service. Our own engineers cannot trivially read your stored files.

Zero Identity Collection

For anonymous transfers, we collect no personally identifiable information. We do not require an email address, phone number, or any form of account registration. The name field on the homepage is an optional label to help you and your recipient identify the upload — it is not stored as a user profile or linked to any identity system.

Ephemeral Data Architecture

Ephemeral storage means data only lives for as long as it is needed. Fylshare's anonymous uploads are not intended as permanent cloud storage. This is by design. Data that is deleted cannot be hacked, subpoenaed, or leaked. We believe the best data security is minimal data retention.

GDPR Compliance

By eliminating account registration for core functionality, Fylshare achieves strong alignment with the GDPR principle of Data Minimization. We do not collect what we do not need. We do not sell user data. We do not serve targeted behavioral advertising from upload activity.

Frequently Asked Questions

Is Fylshare really free?

Yes. Fylshare is 100% free to use. There is no credit card required, no premium subscription, and no hidden fees for the core file sharing functionality. The service is supported by advertising.

Do I need to create an account?

No. Anonymous file uploads require absolutely no registration. You do not need an email address, a username, or a password to upload and share files. Simply go to the homepage, add a name label, upload your files, and get your code.

What is the maximum file size I can upload?

Fylshare supports uploads up to 1GB per session. You can upload multiple files in a single session as long as the total size does not exceed 1 gigabyte.

How long are uploaded files kept?

Anonymous uploads using the 6-digit code system are ephemeral — designed for temporary transfers, not permanent storage. Workspace Box files are stored persistently and remain until you delete them manually from the Box.

Is my data encrypted?

Yes. All files are encrypted in transit using TLS 1.3 and encrypted at rest using AES-256, managed through Google Cloud's Key Management Service. Your data is never stored as plaintext.

Can I use Fylshare on mobile?

Yes. Fylshare is a fully responsive web application. It works on smartphones, tablets, and desktop computers using any modern web browser. There is no app to install.

Who can I contact for support?

You can reach the Fylshare team through our Contact page. We monitor inquiries and aim to respond within 48 hours.

Is Fylshare GDPR compliant?

Fylshare is designed with strong alignment to GDPR's principle of data minimization. We do not collect personally identifiable information for anonymous transfers. Please review our full Privacy Policy for details.
